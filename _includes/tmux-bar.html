{%- comment -%} tmux status bar. The author's real config puts status on TOP, so it goes on top here. Decorative glyphs only; the window list is real navigation. Window numbers come from `forloop.index` over _data/windows.yml and are never written into the markup — `base-index 1` with `renumber-windows on` means the number is positional, so a literal becomes a lie the moment a window moves. The separator is `window-status-separator "#[fg=dim] "`. U+2758 is not in the shipped Maple Mono subset and would render as a tofu box that breaks the cell advance, so main.css draws the separator from a `.tmux__win + .tmux__win::before` pseudo-element instead of the markup emitting a glyph at all. Chosen over a literal `│` because a generated separator never lands in a copied window list, and swapping the near-miss glyph for a 1px rule later stays a CSS-only change. {%- endcomment -%}
