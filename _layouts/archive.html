--- layout: default --- {%- comment -%} Serves jekyll-archives for both /tags/:name/ and /categories/:name/. jekyll-archives sets page.type to the SINGULAR — "category" or "tag" — while the index each one belongs to is the plural in _config.yml's permalinks. This layout used to build both the label and the href as `page.type | append: "s"`, which is right for tags by luck and gives "categorys" for the other half: a dead /categorys/ link and a wrong word, on every category page. English plurals are not a string operation, so the two forms are written out. Both enabled types are covered. Adding one to `jekyll-archives.enabled` means adding it here too, or its pages get an empty href. {%- endcomment -%} {%- case page.type -%} {%- when "category" -%} {%- assign index_path = "/categories/" -%} {%- assign index_name = "categories" -%} {%- when "tag" -%} {%- assign index_path = "/tags/" -%} {%- assign index_name = "tags" -%} {%- endcase -%}
